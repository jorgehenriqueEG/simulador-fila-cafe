# Simulador de Fila de Café
## Descrição do Problema
Um script que simula o tempo de espera de clientes em uma cafeteria, considerando a velocidade do barista e o tipo de pedido.
## Requisitos
* Calcular o tempo de preparo base para cada tipo de bebida.
* Aplicar um multiplicador de dificuldade para bebidas complexas.
* Somar os tempos de todos os clientes na fila.
## Exemplo de Uso
Entrada: [{"nome": "Ana", "bebida": "espresso"}, {"nome": "Bruno", "bebida": "latte"}]
Saída: O tempo total de espera da fila é de 4.5 minutos.
